# Wicons 0.11.0 beta

This beta bundle adds a new transportation-focused icon set and keeps the original 0.10.x files untouched.

- Version: 0.11.0-beta
- Format: SVG line icons at 24x24
- Location: `beta/0.11.0/`
- Manifest: `beta/0.11.0/icons.json`

The bundle contains the new transportation and mobility icons included in the supplied mockup, including renamed and expanded transit variants.
