# Wicons
Outline icon pack for WiOS. 422 icons in 19 categories.

- Grid: 24x24, ~2px safe padding
- Stroke: 1.75, round caps and joins, no fills
- Color: `currentColor` (style with CSS `color`)
- Files: `svg/<category>/wicons-<name>.svg`, `wicons-sprite.svg`, `icons.json` (category manifest), `preview.html`

Sprite usage:
`<svg width="24" height="24"><use href="wicons-sprite.svg#wicons-home"/></svg>`
